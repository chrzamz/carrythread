# Carrythread brand assets

Original SVG artwork for Carrythread · 续迹, created for this project. The mark depicts a continuous thread passing through a folded page. The colour and usage authority is `design/visual-system.md`; positioning and naming checks are in `docs/BRAND.md`.

- `mark.svg`: compact square symbol.
- `wordmark.svg`: English name without the symbol.
- `logo.svg`: symbol and English name.

The wordmark uses a system-font stack. No external font is fetched and no font files are bundled here. The artwork is original; competitor graphics were not used. These source assets follow the repository's license. Product and provider trademarks referenced in documentation remain their owners' marks.

Identical copies live in `site/assets/`. Update both sets together; `node site/check.mjs` checks their equality.
